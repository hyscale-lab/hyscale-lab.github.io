Agentic workloads create systems challenges across both model execution and cloud resource management. This direction studies supporting foundations for efficient reasoning and workload-aware AI infrastructure, treating algorithms and the surrounding cloud stack as a co-design problem rather than optimizing them in isolation.

Current examples include thought pruning for efficient self-consistency scaling and control-plane design that manages workloads rather than treating an AI cluster as a single undifferentiated resource {% cite hong2025slimsc lai2025workloads %}. These works support **Agentic cloud systems**; they do not constitute a complete agentic cloud platform.
