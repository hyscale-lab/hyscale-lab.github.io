This historical research direction studied how to cut cost and improve speed by combining storage-class memory with die-stacked memory technologies in hybrid DIMM-style systems.

The work includes **Design Guidelines for High-Performance SCM Hierarchies** (MEMSYS 2018), **Algorithm/Architecture Co-Design for Near-Memory Processing** (ACM SIGOPS Operating Systems Review, 2018), and **The Mondrian Data Engine** (ISCA 2017). Together, these projects investigated memory hierarchy design and near-memory data processing {% cite ustiugov2018scm drumond2018codesign drumond2017mondrian %}.
